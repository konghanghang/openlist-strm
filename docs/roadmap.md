# 路线图

本文档记录 OpenList-STRM 的交付阶段、当前缺口和后续方向。它不是系统现状文档；当前实现以 [系统架构](./system-architecture.md) 为准。

## 1. 已完成阶段

### Phase 1: MVP

目标：实现核心 STRM 生成功能，CLI 可用。

已完成：

- 项目初始化
- 配置管理模块
- Alist 客户端
- STRM 生成器基础能力
- 增量 / 全量更新
- 定时任务
- SQLite 存储
- 基础日志

### Phase 2: Web UI + API

目标：补齐管理界面和远程触发能力。

已完成：

- REST API
- API Token 认证
- 任务状态查询
- Vue 3 前端基础结构
- 配置管理界面
- 任务管理界面
- 仪表盘界面
- 前端构建与嵌入

### Phase 3: 部署与集成增强

目标：提升部署便利性和外部系统集成能力。

已完成：

- Docker 打包
- Docker Compose 配置
- Webhook 触发能力

## 2. 当前待完成项

这些事项仍有明确产品价值，但当前仓库尚未完全收口：

- 元数据下载
- 文件有效性检测
- UI 进一步优化
- 更完整的测试覆盖
- 错误处理和可观测性继续加强
- 更完整的中英文文档
- CI/CD 收口

## 3. 里程碑

| 里程碑 | 状态 | 说明 |
|--------|------|------|
| M1: MVP | 已完成 | CLI 和核心 STRM 生成功能可用 |
| M2: Web UI + API | 已完成 | 管理界面和 API 已落地 |

## 4. 版本方向

### v1.1

- 支持更多网盘或协议
- 更智能的媒体分类能力
- 可选的轻量刮削能力

### v1.2

- 图形化安装向导
- 多语言支持
- 更可扩展的插件化能力

### v2.0

- 分布式部署可能性
- 消息队列或更稳的异步执行模型
- 监控告警体系

## 5. 维护规则

- 路线图只记录“准备做什么”和“做到了什么阶段”。
- 一旦某项内容已经变成当前系统事实，应同步进入 [系统架构](./system-architecture.md) 或其他现行文档。
- 如果某个规划已经放弃或不再推进，要直接更新状态，不保留模糊占位。
